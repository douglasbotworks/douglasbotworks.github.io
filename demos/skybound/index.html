GAME DEVELOPMENT / NATIVE OPENXR

Skybound.
Above the alpine valley.

A paragliding game in development, combining a procedural mountain landscape, a suspended pilot and changing airflow.

These are exports from the current portable C++ implementation. The game is an experimental reduced-order model. It is not flight training software.

Three ways to explore

Scenic free flight: mountain launch, prescribed wind, ridge lift and stationary thermal columns. No time deadline; landing or reaching the valley boundary ends the flight.

Released thermals: a separate 600-second scene with retained, seeded thermal events that fade and drift horizontally. Restart recreates the same schedule. The flight ends at its simulation-time deadline; pause freezes event age.

Alpine route: three ordered rings in calm air, with a 180-second limit and a completion debrief.

Inspect the thermal schedule

Download the generated event schedule (JSON). Seed 20261014, births below 600 seconds, 120-second event lifetimes. The prescribed column model omits terrain masking, buoyant growth, entrainment and weather calibration. Some event lifetimes extend past the scene deadline; the scene ends before those tails complete.

What has been verified

Portable gameplay checks cover mode selection, repeatable restarts, pause and focus gaps, the deadline, terminal outcome precedence, cockpit labels and the unchanged unlimited default. The portable E2E run also checks the completed calm-air route, output telemetry, scene geometry and native overlay generation.

Current delivery limit: the fresh Android rebuild fails during workspace CMake cleanup. There is no current APK download here. An earlier installed prototype does not contain these latest source changes. Native rendering, controller acceptance, performance and sale readiness remain unverified.
