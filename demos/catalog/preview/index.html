About the CLI edition and availability
This is an early review aid, not an official Shopify tool and not a guarantee that an import is safe. Per file: 15 MiB, 500 columns, 50,000 data records and 1,000,000 cells including the header. Clear removes file selections, pasted text and results from this tab, but does not delete previously downloaded reports. Keep backups and verify the latest Shopify instructions and import settings before making catalog changes.
