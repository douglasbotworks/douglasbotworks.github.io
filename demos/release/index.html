What remains separate

JavaScript runtime behavior, live deployment, accessibility, licensing, security certification and store acceptance. External links are not fetched. References beginning with two or more slashes, including ///cdn.example.test/logo.png, require remote review even when similarly named local files exist. They produce warnings; the strict warning gate blocks packaging. Repeated separators inside local paths, such as assets//logo.svg, also require manual review instead of matching a collapsed filename. These warnings block the strict packaging gate; ordinary single separators remain supported. Literal asset references using file:, blob:, Windows-style C:/ or custom schemes also require manual review. They are never read or fetched; the strict warning gate blocks packaging. Inline data: content is not validated. Text is checked as UTF-8. Conflicting HTML meta or initial CSS encoding declarations require manual review and block strict packaging; server headers, inherited encodings and browser sniffing remain separate acceptance. Server rewrites, DOM-generated anchors and browser image selection require separate checks. An agreed section-link review can additionally check literal HTML IDs and named anchors. That optional scope is not selected in these two sample reports.
