Source lines are each record's starting physical line in its own CSV, including the header, blank lines and line breaks inside quoted fields. Missing rows are not deletion instructions. Duplicate identities compare the first row only and require manual review. Image details include URLs as inert text; images are never loaded. Metadata edits appear as an added and a removed row.

The product overview groups exact Handle spellings and lists finding counts, not risk scores. Blanked cells are also changed cells; categories can overlap. Handle changes appear under both old and new spellings. Image counts combine matched variant rows with edited image URL, position or alt text (once per row) and additional image-row groups (once per participating spelling). Added/absent variants and orphan images have separate categories. Option counts describe normalized product-group findings, not individual images or option values; each participating exact Handle spelling receives the group finding once. Global column/header findings, ambiguous SKUs and warnings remain in their own sections. Products without findings are omitted.

Privacy and limits

  • Packed size checks cover partial proposed values and Requires shipping=false using current header names only. Units, numeric validity, shipping aliases, all-blank size clearing and the complete import schema are not validated.
  • This compares files locally; it does not connect to Shopify or upload either file.
  • Column names are normalized for comparison. Shopify requires exact template headers, including case; verify both files against the current Shopify CSV format.
  • A report is a review aid, not a guarantee that an import is safe. Verify against Shopify's current documentation and your import settings.
