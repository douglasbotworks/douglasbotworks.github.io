Before you install

Keep the extracted folders together and read each product's instructions. A matching SHA256 checks that bytes match the published checksum; it is not a security certification. Native download/file-picker behavior and human acceptance remain unverified in this worker.

For a private repair handoff, agree repository access or an appropriate delivery channel first. If an email service blocks an archive, use the agreed repository or release link. Do not rename executables or otherwise try to bypass mail filters. Leave credentials and customer records out of initial requests.
