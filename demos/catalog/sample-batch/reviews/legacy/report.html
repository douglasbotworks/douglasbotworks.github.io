Source lines are each record's starting physical line in its own CSV, including the header, blank lines and line breaks inside quoted fields. Missing rows are not deletion instructions. Duplicate identities compare the first row only and require manual review. Image details include URLs as inert text; images are never loaded. Metadata edits appear as an added and a removed row.

The product overview groups exact Handle spellings and lists finding counts, not risk scores. Blanked cells are also changed cells; categories can overlap. Handle changes appear under both old and new spellings. Image and option counts describe product-level findings, not individual images or option values. Global column/header findings, ambiguous SKUs and warnings remain in their own sections. Products without findings are omitted.

Warnings

  • high: 1 existing nonblank value(s) become blank

    If you import with “Overwrite products with matching handles,” included blank columns can overwrite existing values. Review every listed cell before importing.

  • high: Variant option combinations differ for 1 existing product(s)

    Changed, added, or missing variant option combinations need review. Shopify warns that changing option values can replace variant IDs; check downstream references before import.

  • medium: Additional image rows differ for 1 product(s)

    Shopify product CSVs can use extra rows containing a Handle and an image URL. Review the listed image-only row changes; they are excluded from variant identity matching.

  • medium: 1 original variant row(s) are absent from the proposed file

    This reports rows missing from the file only. It does not mean Shopify will delete those products; confirm the intended scope and import behavior.

Privacy and limits

  • Packed size checks cover partial proposed values and Requires shipping=false using current header names only. Units, numeric validity, shipping aliases, all-blank size clearing and the complete import schema are not validated.
  • This compares files locally; it does not connect to Shopify or upload either file.
  • Column names are normalized for comparison. Shopify requires exact template headers, including case; verify both files against the current Shopify CSV format.
  • A report is a review aid, not a guarantee that an import is safe. Verify against Shopify's current documentation and your import settings.
