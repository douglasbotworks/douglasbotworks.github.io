What changed in 0.1.1

Untranslated English grammar is no longer highlighted as Spanish. Translated grammar now saves vocabulary and progress, open learning tabs update while browsing, and review cards show the saved Spanish translation.

Already testing? Replace the files in the current unpacked folder, click Reload in Chrome’s Extensions page, then refresh the web page. Keep the folder path and extension ID to preserve learning history; do not remove the extension or clear its storage. Older vocabulary entries gain Spanish text on their next encounter; no reset is needed.

Install in an isolated test profile

  1. Extract the ZIP into a new folder.
  2. In a dedicated Chrome test profile, open the Extensions page and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Open Settings, then test on an ordinary English page. Try pause, site controls and Undo before using it more broadly.

The manifest requests storage, tabs and activeTab permissions and declares content scripts on all URLs. It reads page text to create translations locally. This implementation has no developer-operated server receiving browsing content. Browser-managed model preparation may download files.
