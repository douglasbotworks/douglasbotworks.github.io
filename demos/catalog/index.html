Before you use it

Does a clean report mean an import is safe?

No. This is a comparison aid with bounded checks, not complete Shopify schema validation. Review Shopify’s current import instructions and your import settings. Keep a backup and review the complete report.

What does it flag?

Edited and blanked cells, missing/added variant rows, option-combination differences, image continuation metadata changes, duplicate SKUs and some packed-size risks. It recognizes a documented set of legacy/current header aliases; it does not validate every field.

Where does my data go?

The CLI reads the two local files and writes a local report. It does not upload the files or connect to your store. Reports contain catalog values and should be handled as carefully as the input files. This sample page has no analytics, cookies or contact form.

Is this a finished hosted Shopify app?

This is an early CLI product with automated acceptance coverage. It is independent of Shopify, with no store integration. The free browser preview is linked above and has separate pending native report-download acceptance. It is not part of the proposed paid CLI offer.
